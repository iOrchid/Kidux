遇到问题？

1

卡顿或无响应

强制退出「启椟」（⌥⌘⎋）。活动监视器里若有残留 brew 进程，可结束后再试。批量安装时请避免同时狂跑大量其它终端任务。

2

卸载

将「启椟」拖到废纸篓。可选删除 ~/Library/Application Support/Kidux（仅清本应用数据，不会卸掉已用 brew 安装的软件）。

3

反馈

Bug 请开 Issues；用法问答用 Discussions。源码与构建说明见仓库 README。
